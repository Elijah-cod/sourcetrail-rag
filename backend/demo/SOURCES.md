# Demo collection: sources and licences

The demo collection mixes formats on purpose (Markdown, PDF, CSV) to show multi-source retrieval.

| File | Source | Licence |
|---|---|---|
| `fastapi-*.md` (8 files) | [FastAPI documentation](https://github.com/fastapi/fastapi/tree/6e659e84de09/docs/en/docs), commit `6e659e84de09`, cleaned of website-only markup by `fetch_sources.py` | MIT, © Sebastián Ramírez — see `licenses/FASTAPI-LICENSE.txt` |
| `pgvector-readme.md` | [pgvector README](https://github.com/pgvector/pgvector/blob/f37c13f68b57/README.md), commit `f37c13f68b57`, unmodified | PostgreSQL License, © PostgreSQL Global Development Group / The Regents of the University of California — see `licenses/PGVECTOR-LICENSE.txt` |
| `sourcetrail-overview-2026.pdf` | Original text written for this project, generated by `make_overview_pdf.py` | Same as this repository |
| `postgresql-index-types.csv` | Original summary written for this project | Same as this repository |

To rebuild: `uv run python demo/fetch_sources.py` and `uv run --with reportlab python demo/make_overview_pdf.py` (from `backend/`).
